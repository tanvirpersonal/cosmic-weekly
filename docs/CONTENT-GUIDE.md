# Content guide

1. Add a Markdown file at `content/articles/<slug>.md`.
2. Add matching metadata to `data/articles.json`: slug, title, dek, topic, date, readTime, author, tags and featured.
3. Commit and push to branch `2.0`. Archive, home and search read the index automatically.

Supported syntax includes headings, paragraphs, emphasis, inline code, fenced code, lists, quotes, links and images. Raw HTML is escaped for safety. Use HTTPS for external media.
